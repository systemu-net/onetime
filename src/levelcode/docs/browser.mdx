# LevelCode in your browser

> The LevelCode workbench in a browser tab. Sign in with your account, open a folder or a scratch workspace, and work with the chat panel and the agent. Nothing to install.

The browser edition is the real LevelCode workbench running in a tab. The explorer, editor tabs, themes, the chat panel and the agent are all there. You sign in with the same LevelCode account as the Mac app, and the gateway plan and usage are the same.

The browser edition has a terminal, LevelCode Shell, that works on your files. It does not run programs, so a few things stay in the Mac app. The [full list](#what-stays-in-the-mac-app) is below.

## Open it

Open [LevelCode in your browser](/web) and choose **Open LevelCode**. If you are signed in, **Open in browser** on your [account page](/account) goes to the same place.

The editor opens in the same tab.

## Sign in

The browser edition uses your LevelCode account, the same one you use in the Mac app. The gateway plan and usage are the same as in the Mac app.

Opening the editor from this site signs you in. The editor takes the tab to your LevelCode account and back, in the same tab, so no second window opens. If you are already signed in to your account in this browser, you come straight back.

You can also use a provider key of your own instead of the gateway. The key is kept encrypted in your browser, and requests go from your browser to the provider, so the provider has to accept requests from a web page.

## Where your files live

There are two ways to work with files.

### Open a folder from your computer

LevelCode uses the File System Access API, so edits go straight to the folder you picked. This works in Chrome and Edge.

### Use a scratch workspace

A scratch workspace is saved in your browser. It works in every modern browser, including Safari and Firefox. Clearing the site's data in your browser removes it.

<Note>
  Files stay in your browser or on your computer. [Privacy](#privacy) covers what goes to the model.
</Note>

## What the agent can do here

The agent can read, search, create, edit and delete files in the open workspace. Its changes are applied at once and offered for Keep or Undo.

It can also run commands in LevelCode Shell, the same terminal you can open yourself. See [LevelCode Shell](#levelcode-shell) below for what it does and does not do. Work that needs real programs stays in the Mac app.

## LevelCode Shell

LevelCode Shell is a terminal in the tab. It is bash (pipes, loops, functions, redirections) with about eighty built-in commands, such as `ls`, `cat`, `grep`, `sed`, `awk`, `find`, `sort`, `uniq`, `xargs`, `jq`, `diff` and `tree`. It works on the files of the open workspace.

- **Open it** from the Command Palette with *LevelCode Shell: New Terminal*, or from the Terminal panel.
- **It does not run programs.** There is no Node, npm, git, Python or compiler in it, and no network. `npm test` answers "command not found". Use it to read, search and reshape files: count TODOs, rename a batch of files, run a `sed` over several files, look at a JSON file with `jq`.
- **The agent uses it too.** When the agent runs a command, it runs here. Files it changes are offered for Keep or Undo like any other edit. A command that would touch repository metadata or tool settings (`.git`, `.vscode`, `.github/workflows`, `AGENTS.md` and similar), a file that is not plain text, or a file you have unsaved changes in, is refused as a whole, and nothing from that command is applied.
- **Stop it with Ctrl+C.** A command that is stopped, runs out of time or hits a limit changes nothing.
- **The working folder and exported variables carry from one line to the next.** Functions and shell options do not.

## What stays in the Mac app

These are not in the browser edition.

- Running programs: Node, npm, git, Python, test runners and builds
- Background commands and dev servers
- MCP servers that start local processes
- Installing extensions

They stay in the Mac app. Get it from the [download page](/download), or see [Install and setup](/docs/setup).

## Privacy

Files stay in your browser or on your computer.

The text you send in chat and the files you ask LevelCode to read go to the model through the LevelCode gateway, the same as in the Mac app. [Cloud and billing](/docs/cloud#privacy) explains how requests are routed on the gateway.

## Troubleshooting

<AccordionGroup>
  <Accordion title="After signing in I am not back in the editor">
    Signing in returns to the editor in the same tab. If you end on a page that says you are signed in, use **Open LevelCode in this tab** there: the editor finishes the sign-in when it opens. The sign-in is good for about two minutes.
  </Accordion>

  <Accordion title="I am asked to sign in again, or my workspace is missing">
    The editor keeps your sign-in and your scratch workspace in your browser's site storage (local storage and IndexedDB), not in cookies. Settings that block site data, or that clear it when you close the browser, remove them. Allow site data for the editor's address, and keep it from being cleared when you quit the browser.
